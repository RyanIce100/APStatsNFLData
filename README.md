# APStatsNFLData
This repo will house all the information and regarding my AP Stats final project.

## Information ##

All of the data I used is able to be downloaded from the 'RawData' folder. Alternatively, you can build it yourself using the R files in the 'DataCollection' folder. The 'InterestingFindings' folder houses all of the things I thought were interesting, but could not put on my project due to them referring to the population of the dataset. The images range from scatterplots to summaries by stratum for the datasets.
